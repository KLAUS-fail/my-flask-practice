# Мой учебный проект на Flask 🚀

Это простое веб-приложение, созданное в рамках производственной практики. Оно умеет здороваться с пользователем и работать с динамическими стилями.

## 🛠 Технологии
* **Python 3** — язык программирования.
* **Flask** — микрофреймворк для сайта.
* **HTML5 / CSS3** — верстка и дизайн.
* **GitHub Codespaces** — облачная среда разработки.

## 🚀 Как запустить проект в терминале

Если вы запускаете проект впервые, выполните эти команды по очереди:

1. **Установка зависимостей** (нужна один раз):
    ```bash
   pip install -r requirements.txt

2. Запуск сервера:
    ```bash
    python app.py

3. Просмотр: После запуска перейдите по ссылке, которую выдаст терминал (обычно порт 5000).

📁 Структура проекта

    app.py — серверная логика на Python.
    templates/ — папка с HTML-шаблонами.
    static/ — папка с файлами дизайна (CSS).
    requirements.txt — список нужных библиотек.
